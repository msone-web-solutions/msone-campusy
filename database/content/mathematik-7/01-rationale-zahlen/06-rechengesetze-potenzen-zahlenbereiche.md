## Erklärung

### Die Rechengesetze gelten weiter

Die drei Rechengesetze, die du für natürliche Zahlen kennst, gelten auch für rationale Zahlen:

**Kommutativgesetz (Vertauschungsgesetz):** Bei Addition und Multiplikation darf man die Reihenfolge tauschen.
a + b = b + a und a · b = b · a
Beispiel: (−3) + 7 = 7 + (−3) = 4

**Assoziativgesetz (Verbindungsgesetz):** Bei Addition und Multiplikation darf man beliebig Klammern setzen.
(a + b) + c = a + (b + c) und (a · b) · c = a · (b · c)
Beispiel: (−2 · 5) · 3 = −2 · (5 · 3) = −30

**Distributivgesetz (Verteilungsgesetz):** Eine Zahl mal eine Summe = die Zahl mal jeden Summanden.
a · (b + c) = a · b + a · c
Beispiel: (−4) · (10 + 2) = (−4) · 10 + (−4) · 2 = −40 − 8 = −48

Achtung: Bei **Subtraktion und Division** darf man **nicht** tauschen! 5 − 8 ≠ 8 − 5.

### Rechenvorteile nutzen

Mit den Gesetzen kannst du geschickt rechnen:

- **Passende Zahlen zusammenfassen:** −17 + 25 + 17 − 5 = (−17 + 17) + (25 − 5) = 0 + 20 = **20**
- **Zehner bilden:** (−4) · 7 · (−25) = (−4) · (−25) · 7 = 100 · 7 = **700**
- **Ausklammern:** (−6) · 13 + (−6) · 7 = (−6) · (13 + 7) = (−6) · 20 = **−120**

### Vorrangregeln bei gemischten Aufgaben

Wenn in einer Aufgabe mehrere Rechenarten vorkommen, gilt:

1. **Klammern** zuerst (innen vor außen)
2. **Potenzen**
3. **Punktrechnung** (· und :) vor **Strichrechnung** (+ und −)
4. Sonst **von links nach rechts**

Beispiel: −3 + 4 · (−2) = −3 + (−8) = **−11** (erst mal, dann plus)
Beispiel: (−3 + 4) · (−2) = 1 · (−2) = **−2** (erst Klammer)
Beispiel: 20 : (−4) − 3 · (−2) = −5 − (−6) = −5 + 6 = **1**

### Potenzen mit negativer Basis

Eine Potenz ist eine abgekürzte Multiplikation: 2⁴ = 2 · 2 · 2 · 2 = 16. Die 2 heißt **Basis**, die 4 heißt **Exponent** (Hochzahl).

Mit negativer Basis gilt die Regel „Minuszeichen zählen“:

- (−2)² = (−2) · (−2) = **4** (gerader Exponent → positiv)
- (−2)³ = (−2) · (−2) · (−2) = **−8** (ungerader Exponent → negativ)
- (−2)⁴ = **16**
- (−1)¹⁰⁰ = **1**, (−1)¹⁰¹ = **−1**

**Vorsicht mit der Klammer!** Das ist der häufigste Fehler:

- (−3)² = (−3) · (−3) = **9** – die Klammer sagt: die ganze Zahl −3 wird quadriert.
- −3² = −(3 · 3) = **−9** – ohne Klammer gehört das Minus nicht zur Basis. Es heißt: „das Negative von 3²“.

### Die Zahlenbereiche

Jetzt kennst du mehrere „Sorten“ von Zahlen. Sie bauen aufeinander auf:

- **ℕ – natürliche Zahlen:** 0, 1, 2, 3, 4, … (zum Zählen)
- **ℤ – ganze Zahlen:** …, −3, −2, −1, 0, 1, 2, 3, … (ℕ plus die negativen ganzen Zahlen)
- **ℚ – rationale Zahlen:** alle Zahlen, die man als Bruch schreiben kann, auch negative: −3/4, 0,5, −2, 7, 1/3 …

Jede natürliche Zahl ist auch eine ganze Zahl, und jede ganze Zahl ist auch eine rationale Zahl (7 = 7/1). Man schreibt: **ℕ ⊂ ℤ ⊂ ℚ** („ℕ ist Teilmenge von ℤ, ℤ ist Teilmenge von ℚ“).

Als Mengendiagramm:

```
┌─────────────────────────────────────┐
│ ℚ   −3/4   0,5   −1,25   2/3         │
│   ┌─────────────────────────┐       │
│   │ ℤ   −3   −2   −1        │       │
│   │   ┌─────────────────┐   │       │
│   │   │ ℕ  0  1  2  3 … │   │       │
│   │   └─────────────────┘   │       │
│   └─────────────────────────┘       │
└─────────────────────────────────────┘
```

Mit ℚ⁺ bezeichnet man die **positiven rationalen Zahlen** (die Brüche und Dezimalbrüche aus Klasse 5/6).

Beispiele:
- −5 gehört zu ℤ und ℚ, aber nicht zu ℕ.
- 0,75 gehört nur zu ℚ (und ℚ⁺).
- 12 gehört zu ℕ, ℤ und ℚ.

## Hefteintrag

**Rechengesetze, Potenzen und Zahlenbereiche**

**Rechengesetze** (gelten für + und ·):
Kommutativgesetz: a + b = b + a, a · b = b · a
Assoziativgesetz: (a + b) + c = a + (b + c)
Distributivgesetz: a · (b + c) = a · b + a · c

Rechenvorteil: (−4) · 7 · (−25) = 100 · 7 = 700

**Vorrangregeln:** Klammern → Potenzen → Punkt vor Strich → von links nach rechts
−3 + 4 · (−2) = −3 − 8 = −11

**Potenzen mit negativer Basis:**
(−2)² = 4        (−2)³ = −8
Gerader Exponent → positiv, ungerader Exponent → negativ.
**Achtung:** (−3)² = 9, aber −3² = −9

**Zahlenbereiche:**
ℕ = {0, 1, 2, 3, …} natürliche Zahlen
ℤ = {…, −2, −1, 0, 1, 2, …} ganze Zahlen
ℚ = alle Zahlen, die man als Bruch schreiben kann (auch negativ)
**ℕ ⊂ ℤ ⊂ ℚ**
