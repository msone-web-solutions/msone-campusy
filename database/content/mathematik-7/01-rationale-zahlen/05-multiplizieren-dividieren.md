## Erklärung

### Multiplizieren: Erst der Betrag, dann das Vorzeichen

Beim Multiplizieren rechnest du in zwei Schritten:

1. **Beträge multiplizieren** (so wie du es kennst).
2. **Vorzeichen bestimmen** nach dieser Regel:

| Vorzeichen | Ergebnis |
|---|---|
| (+) · (+) | + |
| (−) · (−) | + |
| (+) · (−) | − |
| (−) · (+) | − |

Kurz: **Gleiche Vorzeichen → Plus. Verschiedene Vorzeichen → Minus.**

**Beispiele:**
- (+3) · (+4) = **12**
- (−3) · (−4) = **12**
- (+3) · (−4) = **−12**
- (−3) · (+4) = **−12**

### Warum ergibt „minus mal minus“ plus?

Das ist die Frage, die alle stellen. Zwei Erklärungen:

**Erklärung mit einem Muster:** Schau dir die Reihe an:
3 · (−2) = −6
2 · (−2) = −4
1 · (−2) = −2
0 · (−2) = 0
(−1) · (−2) = **2**
(−2) · (−2) = **4**
Jedes Mal wird der erste Faktor um 1 kleiner und das Ergebnis um 2 **größer**. Das Muster setzt sich fort – also muss (−1) · (−2) = 2 sein.

**Erklärung mit Schulden:** (−3) · (−5) bedeutet: „3-mal Schulden von 5 € **wegnehmen**“. Wenn dir 3-mal je 5 € Schulden erlassen werden, hast du 15 € **mehr** → +15.

### Dividieren: Dieselbe Regel

Beim Dividieren gilt **genau dieselbe Vorzeichenregel**:

- (+12) : (+3) = **4**
- (−12) : (−3) = **4**
- (+12) : (−3) = **−4**
- (−12) : (+3) = **−4**

Probe: (−4) · (+3) = −12 ✓

### Mehrere Faktoren

Bei mehr als zwei Faktoren zählst du die Minuszeichen:

- **Gerade Anzahl** Minuszeichen (0, 2, 4 …) → Ergebnis **positiv**
- **Ungerade Anzahl** Minuszeichen (1, 3, 5 …) → Ergebnis **negativ**

Beispiel: (−2) · (−3) · (−1) = ? Drei Minuszeichen → negativ. Beträge: 2 · 3 · 1 = 6 → **−6**.
Beispiel: (−2) · (−3) · (−1) · (−5) = ? Vier Minuszeichen → positiv → **+30**.

### Null und Eins

- Jede Zahl mal 0 ergibt 0: (−7) · 0 = 0
- Durch 0 darf man **nie** teilen!
- Eine Zahl mal (−1) ergibt ihre Gegenzahl: 8 · (−1) = −8

### Dezimalbrüche und Brüche

Die Regeln gelten für alle rationalen Zahlen:

- (−0,5) · 6 = **−3**
- (−1,5) · (−2) = **3**
- (−3/4) · 8 = **−6**
- (−2/3) : (−2) = (−2/3) · (−1/2) = **1/3**

### Beispiel: Sachaufgabe

Ein Tauchroboter sinkt jede Minute um 12 m. Wo ist er nach 5 Minuten, wenn er an der Oberfläche (0 m) startet?
5 · (−12) = **−60**. Er ist auf −60 m, also 60 m unter der Oberfläche.

## Hefteintrag

**Multiplizieren und Dividieren rationaler Zahlen**

1. Beträge multiplizieren bzw. dividieren.
2. Vorzeichen bestimmen:

**Gleiche Vorzeichen → Plus. Verschiedene Vorzeichen → Minus.**

| | |
|---|---|
| (+) · (+) = + | (+) : (+) = + |
| (−) · (−) = + | (−) : (−) = + |
| (+) · (−) = − | (+) : (−) = − |
| (−) · (+) = − | (−) : (+) = − |

**Beispiele:**
(−3) · (−4) = 12        (+3) · (−4) = −12
(−12) : (−3) = 4        (−12) : (+3) = −4

**Mehrere Faktoren:** Minuszeichen zählen.
Gerade Anzahl → positiv, ungerade Anzahl → negativ.
(−2) · (−3) · (−1) = −6        (−2) · (−3) · (−1) · (−5) = 30

**Merke:** Durch 0 darf man nie teilen. Eine Zahl mal (−1) ergibt ihre Gegenzahl.
