## Erklärung

### Zahlen vergleichen

Auf der Zahlengerade gilt eine einfache Regel: **Die Zahl, die weiter rechts liegt, ist größer.**

```
 ◄──┼────┼────┼────┼────┼────┼────┼────┼────┼──►
   −4   −3   −2   −1    0    1    2    3    4
        kleiner  ◄────────────────►  größer
```

Daraus folgt:

1. Jede **positive** Zahl ist größer als jede **negative** Zahl. Beispiel: 1 > −100.
2. Die **Null** ist größer als jede negative Zahl und kleiner als jede positive Zahl.
3. Bei zwei **negativen** Zahlen ist die Zahl größer, die **näher an der Null** liegt. Beispiel: −3 > −8, weil −3 näher an der 0 liegt.

Der dritte Punkt ist der Stolperstein! Bei negativen Zahlen dreht sich alles um: **8 > 3**, aber **−8 < −3**.

Denk ans Thermometer: −8 °C ist kälter (kleiner) als −3 °C. Oder an Schulden: Wer −8 € hat, hat weniger als jemand mit −3 €.

Die Zeichen: **<** heißt „ist kleiner als“, **>** heißt „ist größer als“. Die Spitze zeigt immer zur kleineren Zahl.

::: check
type: single_choice
prompt: "Setze das richtige Zeichen: −9 ___ −3"
options: ["<", ">", "="]
answer: { index: 0 }
explanation: "−9 liegt weiter links als −3, also ist −9 kleiner: −9 < −3."
:::

### Zahlen ordnen

Beim Ordnen nach der Größe hilft immer die Zahlengerade. Ordne 2; −5; 0; −1,5; 3,5 der Größe nach (aufsteigend, also von klein nach groß):

−5 < −1,5 < 0 < 2 < 3,5

Erst die negativen Zahlen (die mit der größten „Zahl hinter dem Minus“ zuerst), dann die Null, dann die positiven Zahlen.

### Der Betrag

Der **Betrag** einer Zahl ist ihr **Abstand zur Null** auf der Zahlengerade. Ein Abstand ist nie negativ. Man schreibt den Betrag mit zwei senkrechten Strichen:

- |5| = 5 (die 5 ist 5 Schritte von der 0 entfernt)
- |−5| = 5 (die −5 ist auch 5 Schritte von der 0 entfernt)
- |−2,5| = 2,5
- |0| = 0

Der Betrag „vergisst“ also einfach das Vorzeichen.

**Wozu braucht man das?** Wenn du wissen willst, *wie groß* ein Temperaturunterschied, eine Höhe oder eine Schuld ist – egal in welche Richtung – brauchst du den Betrag. Und beim Rechnen mit negativen Zahlen (nächste Themen!) hilft der Betrag bei den Rechenregeln.

::: check
type: numeric
prompt: "Berechne den Betrag: |−4,5| = ?"
answer: { value: 4.5 }
explanation: "Der Betrag ist der Abstand zur Null: 4,5."
:::

### Die Gegenzahl

Zwei Zahlen, die auf der Zahlengerade **gleich weit von der Null entfernt sind, aber auf verschiedenen Seiten liegen**, heißen **Gegenzahlen** (oder *entgegengesetzte Zahlen*).

- Die Gegenzahl von 4 ist −4.
- Die Gegenzahl von −7 ist 7.
- Die Gegenzahl von −0,5 ist 0,5.
- Die Gegenzahl von 0 ist 0.

Gegenzahlen haben **den gleichen Betrag** und **verschiedene Vorzeichen**. Man bekommt die Gegenzahl, indem man das Vorzeichen umdreht.

::: check
type: numeric
prompt: "Wie heißt die Gegenzahl von −12?"
answer: { value: 12 }
explanation: "Vorzeichen umdrehen: aus −12 wird 12."
:::

### Beispiel: Alles zusammen

Gegeben ist die Zahl −6.

- Betrag: |−6| = 6
- Gegenzahl: 6
- Vergleich: −6 < −2, weil −6 weiter links liegt.
- Vergleich: −6 < 1, weil jede negative Zahl kleiner ist als jede positive.

## Hefteintrag

**Vergleichen, Betrag und Gegenzahl**

**Vergleichen:** Auf der Zahlengerade ist die Zahl **größer**, die weiter **rechts** liegt.

- Jede positive Zahl ist größer als jede negative Zahl: 1 > −100
- Bei negativen Zahlen ist die Zahl größer, die **näher an der Null** liegt: −3 > −8

**Ordnen (aufsteigend):** −5 < −1,5 < 0 < 2 < 3,5

**Betrag:** Der Betrag einer Zahl ist ihr **Abstand zur Null**. Er ist nie negativ.
Schreibweise: |−5| = 5 und |5| = 5

**Gegenzahl:** Zwei Zahlen mit gleichem Betrag, aber verschiedenem Vorzeichen, heißen Gegenzahlen.
Die Gegenzahl von 4 ist −4. Die Gegenzahl von −7 ist 7.
