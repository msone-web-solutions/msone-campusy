## Erklärung

### Die Variable – ein Platzhalter

Ein Kinoticket kostet 8 €. Was kosten 3 Tickets? 3 · 8 €. Und 5 Tickets? 5 · 8 €. Und eine **beliebige Anzahl** Tickets?

Für „beliebige Anzahl“ schreibt man einen Buchstaben: **x**. Dann kosten x Tickets **8 · x** Euro – kurz **8x**.

Der Buchstabe heißt **Variable**. Sie ist ein **Platzhalter für eine Zahl**. Meistens nimmt man x, aber auch a, b, n, t … sind üblich.

### Der Term

Ein **Term** ist ein sinnvoller Rechenausdruck aus Zahlen, Variablen und Rechenzeichen. Beispiele:

- 8x
- 3a + 5
- 2 · (n − 4)
- 12 : y
- 7 (auch eine einzelne Zahl ist ein Term)

**Kein** Term ist z. B. „3 + · 5“ (ergibt keinen Sinn) oder „x = 5“ (das ist eine Gleichung, kein Term).

### Schreibweisen mit Variablen

- Das Malzeichen zwischen Zahl und Variable lässt man weg: 3 · x = **3x**
- Die Zahl steht vor der Variable: x · 3 = **3x** (nicht x3)
- 1 · x = **x** (die 1 schreibt man nicht)
- x · x = **x²**
- x : 4 schreibt man oft als Bruch **x/4**

### Termwerte berechnen

Setzt man für die Variable eine Zahl ein, kann man den Term ausrechnen. Das Ergebnis heißt **Termwert**.

**Beispiel:** T = 3x + 5
- Für x = 2: T = 3 · 2 + 5 = 11
- Für x = 10: T = 3 · 10 + 5 = 35
- Für x = −1: T = 3 · (−1) + 5 = 2
- Für x = 0,5: T = 3 · 0,5 + 5 = 6,5

Am übersichtlichsten ist eine **Wertetabelle**:

| x | −1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|
| 3x + 5 | 2 | 5 | 8 | 11 | 14 |

Tipp: Wenn du eine negative Zahl einsetzt, setze sie **in Klammern**: 3 · (−1). Das vermeidet Vorzeichenfehler.

### Termstrukturen: Was für ein Term ist das?

Man benennt einen Term nach der **Rechenart, die zuletzt ausgeführt wird**:

| Term | Letzte Rechenart | Name |
|---|---|---|
| 3x + 5 | Addition | **Summe** (aus 3x und 5) |
| 2a − 7 | Subtraktion | **Differenz** |
| 4 · (x + 1) | Multiplikation | **Produkt** (aus 4 und (x + 1)) |
| (n − 3) : 2 | Division | **Quotient** |
| (x + 2)² | Potenzieren | **Potenz** |

Zum Beispiel ist 4 · (x + 1) ein **Produkt**, obwohl in der Klammer eine Summe steht – denn zuletzt wird multipliziert.

### Terme aus Texten aufstellen

| Text | Term |
|---|---|
| das Doppelte von x | 2x |
| die Hälfte von x | x/2 |
| um 5 vermehrt | x + 5 |
| um 3 vermindert | x − 3 |
| das Dreifache einer Zahl, vermehrt um 4 | 3x + 4 |
| die Summe aus einer Zahl und 7, verdoppelt | 2 · (x + 7) |
| der Nachfolger von n | n + 1 |
| der Vorgänger von n | n − 1 |
| eine gerade Zahl | 2n |
| eine ungerade Zahl | 2n + 1 |

**Beispiel aus dem Alltag:** Ein Handytarif kostet 10 € Grundgebühr plus 0,05 € pro Minute. Kosten bei m Minuten: **10 + 0,05m**. Für 200 Minuten: 10 + 0,05 · 200 = 20 €.

## Hefteintrag

**Variablen und Terme**

Eine **Variable** (x, a, n …) ist ein **Platzhalter für eine Zahl**.

Ein **Term** ist ein Rechenausdruck aus Zahlen, Variablen und Rechenzeichen: 3x + 5, 2 · (n − 4), x/4

**Schreibweisen:** 3 · x = 3x        1 · x = x        x · x = x²

**Termwert:** Für die Variable eine Zahl einsetzen und ausrechnen.
T = 3x + 5        x = 2: T = 3 · 2 + 5 = 11        x = −1: T = 3 · (−1) + 5 = 2

**Termstruktur** = zuletzt ausgeführte Rechenart:
3x + 5 Summe · 2a − 7 Differenz · 4 · (x + 1) Produkt · (n − 3) : 2 Quotient

**Text → Term:**
das Doppelte: 2x · die Hälfte: x/2 · um 5 vermehrt: x + 5 · um 3 vermindert: x − 3
Nachfolger: n + 1 · gerade Zahl: 2n · ungerade Zahl: 2n + 1
