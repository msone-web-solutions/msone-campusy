## Erklärung

### Gleichartige Glieder zusammenfassen

3 Äpfel + 5 Äpfel = 8 Äpfel. Genauso: **3x + 5x = 8x**.

Glieder mit **derselben Variable** heißen **gleichartig**. Man addiert einfach die Zahlen davor (die **Koeffizienten**).

- 7a − 2a = **5a**
- x + x + x = **3x**
- 4y − 9y = **−5y**

Aber: 3 Äpfel + 5 Birnen kann man nicht zusammenfassen. Genauso: **3x + 5y** bleibt 3x + 5y. Und **3x + 5** bleibt 3x + 5 (Zahl und Variable sind nicht gleichartig).

Auch x und x² sind nicht gleichartig: 2x + x² bleibt so.

::: check
type: single_choice
prompt: "Vereinfache: 6x − 2x"
options: ["4x", "4", "8x"]
answer: { index: 0 }
explanation: "Gleichartige Glieder: 6 − 2 = 4 → 4x."
:::

### Terme mit mehreren Gliedern ordnen

Sortiere erst nach Sorten, dann fasse zusammen:

5x + 3 − 2x + 8 = (5x − 2x) + (3 + 8) = **3x + 11**

Achte auf die Vorzeichen – jedes Vorzeichen gehört zum Glied dahinter:

4a − 7 − 6a + 2 = (4a − 6a) + (−7 + 2) = **−2a − 5**

### Klammern auflösen (ausmultiplizieren)

Das **Distributivgesetz** kennst du: a · (b + c) = a · b + a · c. Mit Variablen:

- 3 · (x + 4) = 3x + 12
- 5 · (2a − 3) = 10a − 15
- −2 · (x + 6) = −2x − 12
- −4 · (y − 1) = −4y + 4 (Minus mal Minus gibt Plus!)

::: check
type: single_choice
prompt: "Multipliziere aus: 4 · (x − 3)"
options: ["4x − 3", "4x − 12", "4x + 12"]
answer: { index: 1 }
explanation: "4 · x = 4x und 4 · (−3) = −12."
:::

### Plus- und Minusklammern

Steht nur ein **Plus** vor der Klammer, kann sie einfach weg:
7 + (2x − 5) = 7 + 2x − 5 = **2x + 2**

Steht ein **Minus** vor der Klammer, drehen sich **alle Vorzeichen** in der Klammer um:
7 − (2x − 5) = 7 − 2x + 5 = **−2x + 12**

Merke: Eine Minusklammer ist wie „mal (−1)“.

::: check
type: single_choice
prompt: "Löse die Klammer auf: 9 − (2x + 1)"
options: ["9 − 2x + 1", "9 − 2x − 1", "9 + 2x − 1"]
answer: { index: 1 }
explanation: "Minusklammer: alle Vorzeichen drehen: 9 − 2x − 1 = 8 − 2x."
:::

### Ausklammern

Ausmultiplizieren rückwärts: Den gemeinsamen Faktor **vor** die Klammer ziehen.

- 6x + 9 = **3 · (2x + 3)** (3 ist in 6 und 9 enthalten)
- 4a − 12 = **4 · (a − 3)**
- 5x + 5 = **5 · (x + 1)**

Probe: Klammer wieder ausmultiplizieren – muss der Ausgangsterm sein.

### Beispiel: Alles zusammen

Vereinfache 3 · (x + 2) − 2 · (x − 4)

1. Ausmultiplizieren: 3x + 6 − 2x + 8
2. Zusammenfassen: (3x − 2x) + (6 + 8) = **x + 14**

Probe mit x = 1: Original 3 · 3 − 2 · (−3) = 9 + 6 = 15. Ergebnis 1 + 14 = 15 ✓

### Beispiel: Umfang eines Rechtecks

Ein Rechteck hat die Seiten x und x + 3. Umfang: x + (x + 3) + x + (x + 3) = **4x + 6**. Oder: 2 · (x + x + 3) = 2 · (2x + 3) = 4x + 6.

## Hefteintrag

**Terme vereinfachen**

**Gleichartige Glieder zusammenfassen** (gleiche Variable):
3x + 5x = 8x        7a − 2a = 5a        4y − 9y = −5y
3x + 5y und 3x + 5 kann man **nicht** zusammenfassen.

**Ordnen und zusammenfassen:**
5x + 3 − 2x + 8 = 3x + 11

**Klammern auflösen:**
3 · (x + 4) = 3x + 12        −4 · (y − 1) = −4y + 4

**Plusklammer:** einfach weglassen. 7 + (2x − 5) = 2x + 2
**Minusklammer:** alle Vorzeichen in der Klammer umdrehen. 7 − (2x − 5) = 7 − 2x + 5 = −2x + 12

**Ausklammern:** gemeinsamen Faktor vor die Klammer.
6x + 9 = 3 · (2x + 3)

**Probe:** eine Zahl einsetzen – Original und Ergebnis müssen denselben Wert haben.
