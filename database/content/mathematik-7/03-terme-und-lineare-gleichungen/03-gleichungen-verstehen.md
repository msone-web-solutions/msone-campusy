## Erklärung

### Was ist eine Gleichung?

Eine **Gleichung** besteht aus **zwei Termen** mit einem **Gleichheitszeichen** dazwischen:

**x + 5 = 12**

Links steht der Term x + 5, rechts der Term 12. Die Gleichung behauptet: Beide Seiten haben denselben Wert.

Ob das stimmt, hängt davon ab, was man für x einsetzt:
- x = 3: 3 + 5 = 8 ≠ 12 → **falsch**
- x = 7: 7 + 5 = 12 ✓ → **wahr**

Die Zahl, die die Gleichung wahr macht, heißt **Lösung**. Hier ist x = 7 die Lösung. Man schreibt die **Lösungsmenge** L = {7}.

### Lösen durch Nachdenken (inhaltlich)

Viele Gleichungen kannst du im Kopf lösen, wenn du sie als Frage liest:

- x + 5 = 12 → „Welche Zahl plus 5 ergibt 12?“ → **7**
- 3x = 21 → „3 mal welche Zahl ist 21?“ → **7**
- x − 4 = 10 → „Welche Zahl minus 4 ist 10?“ → **14**
- x : 2 = 9 → „Welche Zahl geteilt durch 2 ist 9?“ → **18**
- 20 − x = 8 → „20 minus welche Zahl ist 8?“ → **12**

### Lösen durch Probieren

Wenn es nicht sofort klar ist, setze systematisch ein:

2x + 3 = 15
- x = 5: 2 · 5 + 3 = 13 (zu klein)
- x = 6: 2 · 6 + 3 = 15 ✓

Probieren geht bei einfachen Gleichungen, ist aber bei Brüchen oder großen Zahlen mühsam. Deshalb lernst du im nächsten Thema ein sicheres Verfahren: das **Umformen**.

### Das Waagemodell

Stell dir die Gleichung als **Balkenwaage** vor. Links liegen die Sachen der linken Seite, rechts die der rechten. Die Waage ist **im Gleichgewicht**.

```
      x + 5          =          12
   ┌─────────┐               ┌─────────┐
   │ [x] [5] │               │  [12]   │
   └────┬────┘               └────┬────┘
        └────────────▲────────────┘
```

Um herauszufinden, was x wiegt, nimmst du **auf beiden Seiten dasselbe weg** – dann bleibt die Waage im Gleichgewicht:

Nimm auf beiden Seiten 5 weg: links bleibt x, rechts bleibt 12 − 5 = 7. Also **x = 7**.

Diese Idee ist das Herz aller Umformungsregeln: **Was du auf der einen Seite tust, musst du auf der anderen Seite auch tun.**

::: check
type: numeric
prompt: "Auf der linken Waagschale liegen x und 3 kg, rechts 10 kg. Was wiegt x (in kg)?"
answer: { value: 7 }
explanation: "Auf beiden Seiten 3 kg wegnehmen: x = 7 kg."
:::

### Die Probe – immer!

Die **Probe** prüft, ob deine Lösung stimmt: Setze sie in die **ursprüngliche** Gleichung ein und rechne beide Seiten aus.

Gleichung: 2x + 3 = 15, Lösung x = 6
Probe: linke Seite 2 · 6 + 3 = 15, rechte Seite 15. **15 = 15 ✓**

Wenn beide Seiten verschieden sind, hast du dich verrechnet – dann nochmal von vorn.

::: check
type: true_false
prompt: "x = 4 ist eine Lösung von 3x − 2 = 10."
answer: { value: true }
explanation: "Probe: 3 · 4 − 2 = 10 ✓"
:::

### Nicht jede Gleichung hat eine Lösung

Es kommt auf den **Grundbereich** an – also darauf, welche Zahlen für x erlaubt sind.

- x + 5 = 2 → x = −3. In ℕ (natürliche Zahlen) **keine** Lösung: L = { }. In ℤ oder ℚ: L = {−3}.
- 2x = 7 → x = 3,5. In ℤ keine Lösung, in ℚ: L = {3,5}.
- x + 1 = x + 2 → Für **keine** Zahl wahr: L = { } (leere Menge).
- x + x = 2x → Für **jede** Zahl wahr: L = ℚ (alle Zahlen).

Wenn nichts anderes gesagt ist, rechnen wir in ℚ.

## Hefteintrag

**Gleichungen verstehen**

Eine **Gleichung** besteht aus zwei Termen und einem Gleichheitszeichen: x + 5 = 12

Die Zahl, die die Gleichung **wahr** macht, heißt **Lösung**: x = 7, Lösungsmenge L = {7}

**Lösen im Kopf:** Gleichung als Frage lesen.
3x = 21 → „3 mal welche Zahl ist 21?“ → x = 7

**Waagemodell:** Eine Gleichung ist wie eine Waage im Gleichgewicht.
Was man auf der einen Seite tut, muss man auch auf der anderen Seite tun.

**Probe:** Lösung in die **Ausgangsgleichung** einsetzen, beide Seiten ausrechnen.
2x + 3 = 15 mit x = 6:   2 · 6 + 3 = 15   ✓

**Grundbereich:** x + 5 = 2 hat in ℕ keine Lösung (L = { }), in ℚ ist L = {−3}.
