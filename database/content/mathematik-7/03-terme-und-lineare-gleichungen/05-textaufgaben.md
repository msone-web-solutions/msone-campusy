## Erklärung

### Die fünf Schritte

1. **Verstehen:** Was ist gegeben, was ist gesucht? Lies den Text zweimal.
2. **Variable festlegen:** Schreibe auf, wofür x steht – **mit Einheit**. („x = Alter von Lisa in Jahren“)
3. **Gleichung aufstellen:** Übersetze den Text in eine Gleichung.
4. **Gleichung lösen.**
5. **Probe am Text und Antwortsatz:** Passt die Lösung zur Geschichte? Ganzer Satz mit Einheit.

Der wichtigste (und schwerste) Schritt ist Nummer 3. Übe das Übersetzen!

### Übersetzungshilfen

| Text | Mathematik |
|---|---|
| ist, ergibt, beträgt, sind zusammen | = |
| mehr als, vermehrt um, dazu | + |
| weniger als, vermindert um, davon ab | − |
| das Doppelte, Dreifache, mal | 2x, 3x, · |
| die Hälfte, ein Drittel | x/2, x/3 |
| um 5 mehr als x | x + 5 |
| 5 mehr als das Doppelte | 2x + 5 |

### Beispiel 1: Zahlenrätsel

*Wenn man das Dreifache einer Zahl um 8 vermehrt, erhält man 29. Wie heißt die Zahl?*

2. x = die gesuchte Zahl
3. 3x + 8 = 29
4. 3x = 21 → x = 7
5. Probe am Text: Das Dreifache von 7 ist 21, plus 8 ist 29 ✓ **Die Zahl heißt 7.**

### Beispiel 2: Alter

*Papa ist 3-mal so alt wie Ben. Zusammen sind sie 48 Jahre alt. Wie alt ist Ben?*

2. x = Alter von Ben in Jahren. Dann ist Papa 3x Jahre alt.
3. x + 3x = 48
4. 4x = 48 → x = 12
5. Ben 12, Papa 36, zusammen 48 ✓ **Ben ist 12 Jahre alt.**

::: check
type: numeric
prompt: "Das Fünffache einer Zahl, vermindert um 3, ergibt 22. Wie heißt die Zahl?"
answer: { value: 5 }
explanation: "5x − 3 = 22 → 5x = 25 → x = 5."
:::

### Beispiel 3: Geld

*Ein Handytarif kostet 15 € Grundgebühr und 0,20 € pro Minute. Die Rechnung beträgt 27 €. Wie viele Minuten wurde telefoniert?*

2. x = Anzahl der Minuten
3. 15 + 0,2x = 27
4. 0,2x = 12 → x = 60
5. 15 + 0,2 · 60 = 15 + 12 = 27 ✓ **Es wurde 60 Minuten telefoniert.**

### Beispiel 4: Geometrie

*Ein Rechteck ist 5 cm länger als breit. Der Umfang beträgt 38 cm. Wie breit ist es?*

2. x = Breite in cm. Länge = x + 5.
3. Umfang: 2 · (x + x + 5) = 38
4. 2 · (2x + 5) = 38 → 2x + 5 = 19 → 2x = 14 → x = 7
5. Breite 7 cm, Länge 12 cm, Umfang 2 · (7 + 12) = 38 ✓ **Das Rechteck ist 7 cm breit.**

### Beispiel 5: Verteilen

*Drei Freundinnen teilen 90 € so, dass Anna 10 € mehr bekommt als Bea und Cem doppelt so viel wie Bea. Wie viel bekommt jede?*

2. x = Betrag von Bea in €. Anna: x + 10. Cem: 2x.
3. x + (x + 10) + 2x = 90
4. 4x + 10 = 90 → 4x = 80 → x = 20
5. Bea 20 €, Anna 30 €, Cem 40 €. Summe 90 ✓

::: check
type: numeric
prompt: "Lea ist 3 Jahre älter als Tim, zusammen sind sie 17. Wie alt ist Tim?"
answer: { value: 7 }
explanation: "x + (x + 3) = 17 → 2x = 14 → x = 7."
:::

### Wenn die Probe am Text nicht passt

Angenommen, bei einer Altersaufgabe kommt x = −3 heraus. Rechnerisch mag alles stimmen, aber **ein Alter kann nicht negativ sein**. Dann ist die Gleichung falsch aufgestellt – zurück zu Schritt 3. Die Probe am Text schützt dich vor solchen Fehlern.

## Hefteintrag

**Sachaufgaben mit Gleichungen lösen**

**Die fünf Schritte:**
1. Text verstehen: Was ist gegeben, was gesucht?
2. Variable festlegen (mit Einheit): x = …
3. Gleichung aufstellen
4. Gleichung lösen
5. Probe am Text + Antwortsatz

**Übersetzen:** ist/ergibt = · mehr als + · weniger als − · das Doppelte 2x · die Hälfte x/2

**Beispiel:** Papa ist 3-mal so alt wie Ben, zusammen 48 Jahre.
x = Alter von Ben in Jahren, Papa: 3x
x + 3x = 48
4x = 48 | : 4
x = 12
Probe: 12 + 36 = 48 ✓   **Antwort: Ben ist 12 Jahre alt.**

Passt die Lösung nicht zur Geschichte (z. B. negatives Alter), ist die Gleichung falsch aufgestellt.
