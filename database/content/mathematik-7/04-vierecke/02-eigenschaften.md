## Erklärung

Jedes besondere Viereck hat typische Eigenschaften. Die musst du kennen, um Aufgaben zu lösen und um Vierecke zu konstruieren.

### Seiten

| Viereck | Seiten |
|---|---|
| Parallelogramm | gegenüberliegende Seiten parallel **und gleich lang** (a = c, b = d) |
| Rechteck | wie Parallelogramm |
| Raute | **alle vier** Seiten gleich lang |
| Quadrat | alle vier gleich lang |
| Trapez | ein Paar parallel (die Grundseiten) |
| Drachen | **benachbarte** Seiten paarweise gleich (a = d, b = c) |

::: check
type: single_choice
prompt: "Bei welchem Viereck sind alle vier Seiten gleich lang und die Diagonalen senkrecht, aber die Winkel nicht 90°?"
options: ["Rechteck", "Raute", "Trapez"]
answer: { index: 1 }
explanation: "Das ist die Raute."
:::

### Winkel

| Viereck | Winkel |
|---|---|
| Parallelogramm | gegenüberliegende Winkel gleich (α = γ, β = δ); benachbarte ergänzen sich zu 180° (α + β = 180°) |
| Rechteck, Quadrat | alle vier Winkel 90° |
| Raute | wie Parallelogramm |
| Trapez | Winkel an einem Schenkel ergänzen sich zu 180° (α + δ = 180°) |
| Drachen | die beiden Winkel zwischen ungleichen Seiten sind gleich (β = δ) |

**Beispiel:** In einem Parallelogramm ist α = 65°. Dann ist γ = 65° und β = δ = 180° − 65° = 115°.

::: check
type: numeric
prompt: "In einem Parallelogramm ist α = 55°. Wie groß ist β?"
options: { unit: "°" }
answer: { value: 125 }
explanation: "Benachbarte Winkel ergänzen sich zu 180°: 180 − 55 = 125°."
:::

### Diagonalen

| Viereck | Diagonalen |
|---|---|
| Parallelogramm | **halbieren sich** gegenseitig |
| Rechteck | halbieren sich und sind **gleich lang** |
| Raute | halbieren sich und stehen **senkrecht** aufeinander, halbieren die Winkel |
| Quadrat | halbieren sich, gleich lang, senkrecht |
| Drachen | stehen **senkrecht** aufeinander; die Symmetriediagonale halbiert die andere |
| Trapez | keine besondere Eigenschaft |

Das ist eine gute Merkhilfe für das Haus der Vierecke: Das Quadrat hat **alle** Diagonaleigenschaften, weil es Rechteck und Raute zugleich ist.

### Symmetrie

**Achsensymmetrie** – man kann die Figur so falten, dass beide Hälften aufeinanderliegen:

| Viereck | Symmetrieachsen |
|---|---|
| Quadrat | **4** (2 Diagonalen + 2 Mittellinien) |
| Rechteck | **2** (die Mittellinien – nicht die Diagonalen!) |
| Raute | **2** (die Diagonalen) |
| Drachen | **1** (eine Diagonale) |
| gleichschenkliges Trapez | **1** (Mittelsenkrechte der Grundseiten) |
| Parallelogramm | **keine** |

**Punktsymmetrie** – die Figur sieht nach Drehung um 180° gleich aus. Parallelogramm, Rechteck, Raute und Quadrat sind punktsymmetrisch zum Schnittpunkt der Diagonalen.

::: check
type: numeric
prompt: "Wie viele Symmetrieachsen hat eine Raute?"
answer: { value: 2 }
explanation: "Die beiden Diagonalen."
:::

### Besondere Linien einzeichnen

- **Diagonalen:** Ecke zu gegenüberliegender Ecke.
- **Mittellinien:** verbinden die Mittelpunkte gegenüberliegender Seiten.
- **Höhen:** Abstand zwischen zwei parallelen Seiten, senkrecht gemessen (wichtig für den Flächeninhalt).
- **Symmetrieachsen:** wie oben beschrieben.

### Beispiel: Viereck bestimmen

Ein Viereck hat Diagonalen, die gleich lang sind und sich halbieren, aber nicht senkrecht aufeinander stehen. Was ist es?
Gleich lang + halbieren sich → Rechteck. Nicht senkrecht → kein Quadrat. Also ein **Rechteck** (das kein Quadrat ist).

## Hefteintrag

**Eigenschaften der Vierecke**

| | Seiten | Winkel | Diagonalen | Symmetrieachsen |
|---|---|---|---|---|
| **Parallelogramm** | gegenüber parallel und gleich lang | gegenüber gleich, benachbart 180° | halbieren sich | 0 (punktsymm.) |
| **Rechteck** | gegenüber gleich lang | alle 90° | halbieren sich, gleich lang | 2 (Mittellinien) |
| **Raute** | alle gleich lang | gegenüber gleich | halbieren sich, senkrecht | 2 (Diagonalen) |
| **Quadrat** | alle gleich lang | alle 90° | halbieren sich, gleich lang, senkrecht | 4 |
| **Drachen** | Nachbarseiten paarweise gleich | β = δ | senkrecht | 1 (Diagonale) |
| **Trapez** | ein Paar parallel | am Schenkel 180° | – | gleichschenklig: 1 |

Beispiel Parallelogramm: α = 65° → γ = 65°, β = δ = 115°

**Besondere Linien:** Diagonale = Ecke zu Gegenecke · **Mittellinie** verbindet die Mittelpunkte gegenüberliegender Seiten · **Höhe** = senkrechter Abstand paralleler Seiten
