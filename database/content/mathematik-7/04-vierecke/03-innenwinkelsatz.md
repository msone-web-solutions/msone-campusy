## Erklärung

### Der Satz

**In jedem Viereck beträgt die Summe der Innenwinkel 360°.**

α + β + γ + δ = 360°

Das gilt für **jedes** Viereck – egal ob Quadrat, Trapez oder ein ganz schiefes Viereck.

### Warum ist das so? Die Begründung

Du weißt schon aus Klasse 6: Im **Dreieck** ist die Winkelsumme **180°**.

Zeichne in ein beliebiges Viereck ABCD die **Diagonale AC** ein. Sie teilt das Viereck in **zwei Dreiecke**: ABC und ACD.

```
        D ─────────── C
       / \          ⁄ |
      /   \  ACD  ⁄   |
     /     \    ⁄     |
    /  ABC  \ ⁄       |
   A ─────────────── B
```

- Im Dreieck ABC: Winkelsumme 180°.
- Im Dreieck ACD: Winkelsumme 180°.
- Zusammen: 180° + 180° = **360°**.

Und die Winkel der beiden Dreiecke ergeben genau die vier Winkel des Vierecks: β und δ bleiben ganz, α und γ werden von der Diagonale in je zwei Teile zerlegt, die zusammen wieder α bzw. γ ergeben.

Das ist ein **Beweis**: Wir haben den neuen Satz auf etwas zurückgeführt, das wir schon wissen (Winkelsumme im Dreieck). So funktioniert Mathematik.

### Rechnen mit dem Innenwinkelsatz

**Beispiel 1:** Drei Winkel sind bekannt: α = 80°, β = 95°, γ = 110°. Gesucht: δ.
δ = 360° − 80° − 95° − 110° = **75°**

**Beispiel 2:** Parallelogramm mit α = 50°.
α = γ = 50°. Dann: β + δ = 360° − 100° = 260°, und weil β = δ: β = δ = **130°**.
(Schneller: β = 180° − 50° = 130°.)

**Beispiel 3:** Drachen mit α = 100° und γ = 60°. Gesucht: β und δ.
β + δ = 360° − 100° − 60° = 200°. Im Drachen ist β = δ, also β = δ = **100°**.

**Beispiel 4:** Trapez mit α = 70° und β = 85° (a ∥ c).
δ = 180° − α = 110° (Winkel am Schenkel). γ = 180° − β = 95°.
Probe: 70 + 85 + 95 + 110 = 360 ✓

**Beispiel 5:** Mit einer Variablen: Die Winkel eines Vierecks sind x, 2x, 3x und 4x.
x + 2x + 3x + 4x = 360° → 10x = 360° → x = 36°. Die Winkel: 36°, 72°, 108°, 144°.

### Sonderfall: Überstumpfe Winkel

Ein Viereck kann einen **einspringenden** Winkel haben (größer als 180°), es sieht dann wie ein Pfeil aus. Auch dann gilt die Winkelsumme 360°.

### Außenwinkel

Der **Außenwinkel** an einer Ecke ergänzt den Innenwinkel zu 180°. Bei α = 80° ist der Außenwinkel 100°. Die vier Außenwinkel eines Vierecks ergeben zusammen ebenfalls 360°.

## Hefteintrag

**Innenwinkelsatz im Viereck**

**In jedem Viereck gilt: α + β + γ + δ = 360°**

**Begründung:** Eine Diagonale zerlegt das Viereck in zwei Dreiecke. Jedes Dreieck hat die Winkelsumme 180°. Zusammen: 2 · 180° = 360°.

**Beispiel:** α = 80°, β = 95°, γ = 110°
δ = 360° − 80° − 95° − 110° = 75°

**Parallelogramm:** α = γ, β = δ, α + β = 180°
α = 50° → γ = 50°, β = δ = 130°

**Trapez (a ∥ c):** α + δ = 180°, β + γ = 180°

**Mit Variable:** Winkel x, 2x, 3x, 4x → 10x = 360° → x = 36°
