## Erklärung

Prozente sieht man überall in Diagrammen: Wahlergebnisse, Umfragen, Akkuanzeigen. Drei Diagrammarten musst du kennen.

### Das Säulendiagramm (Balkendiagramm)

Jede Kategorie bekommt eine **Säule**, die Höhe zeigt den Wert (z. B. in Prozent). Gut zum **Vergleichen** von Kategorien.

```
Lieblingssport der 7a (in %)
40 │      ██
30 │      ██   ██
20 │ ██   ██   ██
10 │ ██   ██   ██   ██
 0 └─────────────────────
    Fußb. Schw. Reiten Tennis
     20    40    30     10
```

Beim Zeichnen: Achsen beschriften, gleiche Säulenbreite, gleiche Abstände, sinnvolle Skala (hier 10er-Schritte).

### Das Kreisdiagramm

Der ganze Kreis ist **100 %** = **360°**. Jeder Anteil wird zu einem **Kreissektor** („Tortenstück“). Gut zum Zeigen, **wie sich ein Ganzes aufteilt**.

**Umrechnung Prozent → Winkel:** 1 % entspricht 3,6° (weil 360° : 100 = 3,6°).

| Anteil | Winkel |
|---|---|
| 100 % | 360° |
| 50 % | 180° |
| 25 % | 90° |
| 10 % | 36° |
| 1 % | 3,6° |

**Beispiel:** Fußball 20 % → 20 · 3,6° = **72°**. Schwimmen 40 % → **144°**. Reiten 30 % → **108°**. Tennis 10 % → **36°**. Kontrolle: 72 + 144 + 108 + 36 = 360° ✓

So zeichnest du es: Kreis mit Zirkel, einen Radius als Startlinie, dann mit dem Geodreieck die Winkel nacheinander abtragen.

**Umrechnung Winkel → Prozent:** Winkel : 3,6. Ein Sektor mit 54° entspricht 54 : 3,6 = **15 %**.

Wenn keine Prozente, sondern Anzahlen gegeben sind: Erst den Anteil berechnen. 6 von 24 Kindern → 6/24 = 25 % → 90°. (Oder direkt: 360° : 24 · 6 = 90°.)

### Das Liniendiagramm

Zeigt, wie sich ein Wert **über die Zeit verändert**. Die Punkte werden mit Linien verbunden. Gut für **Entwicklungen** (Temperatur im Tagesverlauf, Akkustand, Preise über Jahre).

```
Akku (%)
100 │●
 75 │  ╲
 50 │    ●───●
 25 │          ╲
  0 └───────────●──
    8   10  12  14 Uhr
```

answer: { value: 10 }

:::

### Diagramme auswerten – und kritisch lesen

Beim Auswerten fragst du: Was ist die **größte / kleinste** Kategorie? Wie groß ist der **Unterschied**? Wie viel ist das in **absoluten Zahlen**?

*Beispiel:* 30 % der 7a (25 Kinder) reiten gern → 25 · 0,3 = 7,5 → das kann nicht sein! Bei 25 Kindern muss der Anteil ein Vielfaches von 4 % sein. Die Angaben im Diagramm sind gerundet – bei kleinen Gruppen musst du das beachten.

**Vorsicht bei Tricks:** Eine y-Achse, die nicht bei 0 beginnt, lässt kleine Unterschiede riesig aussehen. 3D-Torten verzerren die Anteile. Schau immer auf die Achsenbeschriftung!
